# Konsole

Deploy to `~/.local/share/konsole/`:

1. Copy `rose-pine.colorscheme` and `Profile 1.profile` there.
2. In Konsole: Settings → Edit Current Profile → Appearance → select **rose-pine**.

`rose-pine.colorscheme` is the official port from
[rose-pine/konsole](https://github.com/rose-pine/konsole), modified to 85%
opacity (`Opacity=0.5`) with window blur (`Blur=true`) for a frosted
background. Both map to the "Background color transparency" slider and "Blur
background" checkbox in the Color Scheme Editor. The profile is the default
"Profile 1" with `ColorScheme=rose-pine` added; the font stays Hack 19.
